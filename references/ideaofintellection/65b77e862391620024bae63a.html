Archived reference note

English translation of the archived note. JP shows the original text. Source links and literal code are retained; the translation does not update or independently verify the source claims.

When rainwater alone is insufficient, water is supplied from irrigation channels and other sources, while excess water is drained. This enables more efficient and stable crop production, making it an effective drought countermeasure. Farming using only rainwater is called “rainfed agriculture.” Arid regions generally enjoy favorable sunlight conditions and can produce more stable, high-quality crops if water can be secured.
雨水のみで足りない場合は用水路などから水を補給し、過剰な水は排水することで、より効率的且つ安定的な作物生産を行うことができるため、干ばつの有効な対策手段です。 一方、雨水のみにより作物を育てる農業を「天水農業」と呼びます。 乾燥地域は、一般に日照環境に恵まれ、水が確保できればより安定的で高品質な作物の生産ができます。
