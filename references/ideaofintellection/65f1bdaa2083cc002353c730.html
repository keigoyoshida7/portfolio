English translation of the archived note. JP shows the original text. Source links and literal code are retained; the translation does not update or independently verify the source claims.

Statistics. Statistical adjustment for multiple testing when several statistical tests are performed simultaneously. To avoid numerous false positives (Type 1 errors), the significance level (α) must be lowered with consideration of the number of comparisons performed. One of several methods used to counter the multiple-comparisons problem. #analysis
統計学。 複数の統計学的検定を同時に行う場合における、多重検定の統計学的な調整。 多数の偽陽性（第1種の過誤）が生じるのを避けるため、行う比較の数を考慮して有意水準（α値）を下げる必要がある。 多重比較問題に対抗するために使われるいくつかの手法のうちの1つである。 #analysis
