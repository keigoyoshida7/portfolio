配置の方法 / Mapping method

題名・本文の日本語 2–5 文字 n-gram と英語単語の TF-IDF に、実際のタグ・共通参照の特徴を合わせ、コサイン類似度を計算します。元の計算された48群は、原典内の直接リンクと類似度のグラフを Louvain で群分けし、階層的な三次元の力学配置を行っています。元の群内の細分には 64 次元 SVD と k-means を使います。読み直して追加したテーマ群は、関連領域の近くに配置し、群内の語彙特徴を3次元 SVD で配置します。

The graph combines source links with cosine similarity over TF-IDF features from titles, text, tags and shared references, using Japanese character n-grams and English words. The original 48 computed groups use Louvain communities and a hierarchical 3D force layout; 64-dimensional SVD and k-means refine their subgroups. The added source-reviewed themes sit near related regions, with 3D SVD arranging lexical features within each theme.
